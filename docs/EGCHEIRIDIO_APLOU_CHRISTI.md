# Εγχειρίδιο Απλού Χρήστη (Υπαλλήλου)

**Σύστημα:** ΠΔΕΔΕ — Διαχείριση Αιτήσεων Άδειας  
**Διεύθυνση εφαρμογής:** https://adeies.pdede.gov.gr  
**Κοινό:** Υπάλληλοι που υποβάλλουν αιτήσεις άδειας  
**Έκδοση:** Ιούλιος 2026  

> **Αναπληρωτές:** η βασική χρήση είναι ίδια με αυτό το εγχειρίδιο.  
> Για όσα ισχύουν **μόνο** για αναπληρωτές (σύμβαση, μηδενισμός υπολοίπου, μπλοκ αιτήσεων), δείτε το  
> **[Παράρτημα Αναπληρωτή](EGCHEIRIDIO_ANAPLIROTI.md)**.

---

## 1. Πρώτη είσοδος και σύνδεση

1. Ανοίξτε τη διεύθυνση **https://adeies.pdede.gov.gr**.
2. Πατήστε σύνδεση μέσω **ΠΣΔ (σχ.gr / SSO)**.
3. **Πρώτη φορά:** συμπληρώστε τη φόρμα στοιχείων (όνομα με πεζά/κεφαλαία κανονικά, τμήμα κ.λπ.) και υποβάλετε.
4. Περιμένετε **ενεργοποίηση** από το τμήμα αδειών. Θα λάβετε ειδοποίηση/email όταν εγκριθείτε.
5. Ξανασυνδεθείτε με ΠΣΔ. Μεταφέρεστε στο **Dashboard υπαλλήλου**.

### Τι βλέπετε στο dashboard
- Υπόλοιπο κανονικής άδειας (όπου ισχύει)
- Λίστα αιτήσεών σας
- Κουμπί **Νέα αίτηση**
- Ειδοποιήσεις (καμπανάκι)

---

## 2. Τι μπορείτε / τι δεν μπορείτε να κάνετε

### Μπορείτε
- Να δημιουργείτε και να υποβάλλετε αιτήσεις άδειας
- Να παρακολουθείτε την πορεία κάθε αίτησης
- Να ανακαλείτε αίτηση που δεν έχει ολοκληρωθεί ακόμα (**Ανάκληση αίτησης**)
- Να ανακαλείτε ολοκληρωμένη άδεια ολικά ή μερικώς (**Ανάκληση άδειας**)
- Να ανεβάζετε δικαιολογητικά όταν σας ζητηθούν
- Να βλέπετε το υπόλοιπο και το ιστορικό κινήσεων (ledger), όπου εμφανίζεται

### Δεν κάνετε
- Έγκριση αιτήσεων άλλων
- Καταχώρηση πρωτοκόλλου
- Ετοιμασία αποφάσεων / ΣΗΔΕ

---

## 3. Νέα αίτηση άδειας — βήμα προς βήμα

1. Πατήστε **Νέα αίτηση άδειας**.
2. Επιλέξτε **τύπο άδειας**  
   (μην επιλέξετε «Ανάκληση» εδώ — η ανάκληση ολοκληρωμένης άδειας γίνεται από την ίδια την ολοκληρωμένη αίτηση).
3. Διαβάστε τυχόν **οδηγίες** του τύπου και συμπληρώστε αιτιολογία αν ζητείται.
4. Δηλώστε **διαστήματα** (από–έως). Το σύστημα υπολογίζει εργάσιμες ημέρες (χωρίς Σ/Κ και αργίες, όπου ισχύει).
5. Επισυνάψτε αρχεία αν απαιτούνται (συνήθως PDF / εικόνες).
6. Αποθηκεύστε ως **πρόχειρο** ή προχωρήστε σε **υποβολή**.

| Ενέργεια | Αποτέλεσμα |
|----------|------------|
| Πρόχειρο | Μπορείτε να επεξεργαστείτε / διαγράψετε αργότερα |
| Υποβολή | Η αίτηση προχωρά στη ροή (προϊστάμενος / πρωτόκολλο κ.λπ.) |

**Μετά την υποβολή** δεν αλλάζετε διαστήματα (εκτός αν σας επιστραφεί η αίτηση ή ζητηθούν δικαιολογητικά).

---

## 4. Καταστάσεις αίτησης (τι σημαίνουν για εσάς)

| Κατάσταση | Τι σημαίνει |
|-----------|-------------|
| Πρόχειρη | Δεν έχει υποβληθεί |
| Υποβληθείσα | Περιμένει έγκριση προϊσταμένου |
| Εκκρεμεί Πρωτόκολλο ΚΕΔΑΣΥ/ΚΕΠΕΑ | Αν ανήκετε σε ΚΕΔΑΣΥ/ΚΕΠΕΑ/ΣΔΕΥ υπό ΚΕΔΑΣΥ |
| Για πρωτόκολλο ΠΔΕΔΕ | Έχει εγκριθεί· το τμήμα αδειών την παραλαμβάνει |
| Σε επεξεργασία | Την επεξεργάζεται το τμήμα αδειών |
| Σε αναμονή δικαιολογητικών | **Πρέπει να ανεβάσετε** έγγραφα |
| Ετοιμασία απόφασης | Ετοιμάζεται η απόφαση |
| Υγειονομική Επιτροπή | Αναμονή ΥΕ (συνήθως αναρρωτικές) |
| ΣΗΔΕ — προς υπογραφές | Η απόφαση είναι για υπογραφές |
| Ολοκληρώθηκε | Η άδεια χορηγήθηκε |
| Απόρριψη προϊσταμένου / τμήματος αδειών | Δεν εγκρίθηκε |
| Ανάκληση από αιτούντα | Εσείς ακυρώσατε την αίτηση |
| ΑΝΑΚΛΗΣΗ ΑΔΕΙΑΣ ΑΠΟ ΑΙΤΗΣΗ | Η ολοκληρωμένη άδεια ανακλήθηκε πλήρως |

---

## 5. Δικαιολογητικά

1. Όταν η κατάσταση γίνει **Σε αναμονή δικαιολογητικών**, ανοίξτε την αίτηση.
2. Ανεβάστε τα ζητούμενα αρχεία.
3. Πατήστε **Ολοκλήρωση αποστολής** (αν εμφανίζεται).
4. Περιμένετε συνέχεια από το τμήμα αδειών.

---

## 6. Υπόλοιπο κανονικής άδειας

- Το υπόλοιπο **αφαιρείται όταν η αίτηση ολοκληρωθεί**, όχι απλώς όταν εγκρίνει ο προϊστάμενος.
- Στο **Ιστορικό υπολοίπου (ledger)** βλέπετε κάθε κίνηση (+/− ημέρες, αιτία, υπόλοιπο μετά).
- Αν το νούμερο στο dashboard δεν συμφωνεί με το ledger, ενημερώστε τον χειριστή αδειών.

---

## 7. Ανάκληση αίτησης vs Ανάκληση άδειας

| | Ανάκληση **αίτησης** | Ανάκληση **άδειας** |
|--|----------------------|---------------------|
| Πότε | Πριν ολοκληρωθεί | Μόνο όταν είναι **Ολοκληρωμένη** |
| Αποτέλεσμα | Η αίτηση ακυρώνεται | Νέα αίτηση που ακυρώνει ολικά/μερικώς την άδεια· μπορεί να επιστρέψει ημέρες |

**Ανάκληση αίτησης** επιτρέπεται συνήθως σε: Υποβληθείσα, Εκκρεμεί πρωτ. ΚΕΔΑΣΥ, Αναμονή δικαιολογητικών, Σε επεξεργασία, Ετοιμασία απόφασης.  
**Δεν** επιτρέπεται π.χ. σε: Για πρωτόκολλο ΠΔΕΔΕ, Υγειονομική, Προς υπογραφές, Ολοκληρωμένη.

**Ανάκληση άδειας:** ανοίξτε ολοκληρωμένη αίτηση → Ολική ή Μερική → υποβολή (ακολουθεί έγκριση όπως κανονική αίτηση). Δεν μπορείτε να έχετε δύο ανοιχτές ανακλήσεις για την ίδια άδεια.

## 8. Ειδικές περιπτώσεις (σύντομα)

| Περίπτωση | Τι να ξέρετε |
|-----------|----------------|
| Κανονική άδεια | Χρειάζεται επαρκές υπόλοιπο |
| Αναρρωτική με ΥΔ | Συνήθως έως **2** ολοκληρωμένες ανά έτος |
| Αναρρωτική με γνωμάτευση | Μπορεί να ζητηθούν δικαιολογητικά / ΥΕ |
| ΚΕΔΑΣΥ / ΣΔΕΥ | Μπορεί να προηγηθεί πρωτόκολλο ΚΕΔΑΣΥ |
| Άτυπη άδεια | Μόνο αν το τμήμα σας το επιτρέπει· απλούστερη ροή |
| Αναπληρωτές | Δείτε το [Παράρτημα Αναπληρωτή](EGCHEIRIDIO_ANAPLIROTI.md) |

---

## 9. Τι κάνετε ανά κατάσταση (σύνοψη)

| Κατάσταση | Ενέργειές σας |
|-----------|----------------|
| Πρόχειρη | Επεξεργασία, υποβολή, διαγραφή |
| Υποβληθείσα / ΚΕΔΑΣΥ / Επεξεργασία / Ετοιμασία απόφασης | Προβολή, ανάκληση αίτησης (αν εμφανίζεται) |
| Αναμονή δικαιολογητικών | Ανέβασμα αρχείων, ολοκλήρωση αποστολής |
| Πρωτόκολλο ΠΔΕΔΕ / ΥΕ / Υπογραφές | Προβολή / αναμονή |
| Ολοκληρώθηκε | Προβολή, ανάκληση άδειας |
| Απορριφθείσα / Ανακληθείσα | Μόνο προβολή |

---

## 10. Συχνά προβλήματα

| Πρόβλημα | Τι να κάνετε |
|----------|----------------|
| Δεν με αφήνει να συνδεθώ / εκκρεμεί έγκριση | Περιμένετε ενεργοποίηση από το τμήμα αδειών |
| Δεν μπορώ να υποβάλω αίτηση | Ελέγξτε δικαίωμα αίτησης, υπόλοιπο, σύμβαση (αναπληρωτές), όριο ΥΔ |
| Κολλημένη σε «Υποβληθείσα» | Περιμένετε προϊστάμενο· αν αργεί πολύ, ενημερώστε |
| Κολλημένη σε πρωτόκολλο ΚΕΔΑΣΥ | Ενημερώστε τη γραμματεία ΚΕΔΑΣΥ |
| Δεν βλέπω «Ανάκληση άδειας» | Πρέπει να είναι Ολοκληρωμένη και χωρίς άλλη ανοιχτή ανάκληση |
| Δεν ανεβαίνει αρχείο | Ελέγξτε τύπο/μέγεθος· προτιμήστε PDF |
| Υπόλοιπο λάθος | Επικοινωνήστε με χειριστή αδειών |

Για τεχνικό σφάλμα σημειώστε: **αριθμό αίτησης**, ημερομηνία/ώρα και μήνυμα οθόνης.
