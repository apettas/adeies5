# Εγχειρίδιο Απλού Χρήστη (Υπαλλήλου)

**Σύστημα:** ΠΔΕΔΕ — Διαχείριση Αιτήσεων Άδειας  
**Κοινό:** Υπάλληλοι που υποβάλλουν αιτήσεις άδειας (`EMPLOYEE`)  
**Έκδοση οδηγού:** Ιούλιος 2026  

---

## 1. Τι μπορείτε να κάνετε

- Να δημιουργείτε και να υποβάλλετε αιτήσεις άδειας.
- Να παρακολουθείτε την πορεία κάθε αίτησης.
- Να ανακαλείτε αίτηση που δεν έχει ολοκληρωθεί ακόμα (**Ανάκληση αίτησης**).
- Να ανακαλείτε ολοκληρωμένη άδεια ολικά ή μερικώς (**Ανάκληση άδειας**).
- Να ανεβάζετε δικαιολογητικά όταν σας ζητηθούν.
- Να βλέπετε το υπόλοιπο κανονικών αδειών σας (όπου εμφανίζεται).

### Τι δεν κάνετε
- Δεν εγκρίνετε αιτήσεις άλλων.
- Δεν καταχωρείτε πρωτόκολλο.
- Δεν ετοιμάζετε αποφάσεις ΣΗΔΕ.

## 3. Καταστάσεις που θα δείτε στις αιτήσεις σας

| Εμφάνιση | Τι σημαίνει για εσάς |
|----------|----------------------|
| Πρόχειρη | Δεν έχει υποβληθεί ακόμα — μπορείτε να επεξεργαστείτε / διαγράψετε / υποβάλετε |
| Υποβληθείσα | Περιμένει έγκριση προϊσταμένου |
| Εκκρεμεί Πρωτόκολλο ΚΕΔΑΣΥ/ΚΕΠΕΑ | Περιμένει πρωτόκολλο υπηρεσίας (αν ανήκετε σε τέτοια δομή) |

| Σε επεξεργασία | Την επεξεργάζεται το τμήμα αδειών |

| Ανάκληση από αιτούντα | Εσείς ακυρώσατε την αίτηση |

## 4. Ροή από την αρχή έως το τέλος

### 4.1 Νέα αίτηση άδειας

1. Πατήστε **Νέα αίτηση άδειας**.
2. Επιλέξτε **τύπο άδειας** (όχι «Ανάκληση» — αυτή γίνεται μόνο από ολοκληρωμένη άδεια).
3. Συμπληρώστε αιτιολογία αν χρειάζεται και διαβάστε τυχόν οδηγίες του τύπου.
4. Δηλώστε **ημέρες** και **διαστήματα** (από–έως). Τα διαστήματα πρέπει να συμφωνούν με τις ημέρες.
5. Επισυνάψτε αρχεία αν απαιτούνται (PDF, εικόνες κ.λπ.).
6. Προεπισκόπηση → επιβεβαίωση → υποβολή.
7. Συνήθως δημιουργείται PDF και μπορεί να σταλεί αυτόματα στο πρωτόκολλο.

**Μετά την υποβολή** η αίτηση παύει να είναι πρόχειρη. Η επόμενη κατάσταση εξαρτάται από τον τύπο και το τμήμα σας (έγκριση προϊσταμένου, πρωτόκολλο ΚΕΔΑΣΥ, ή απευθείας ΠΔΕΔΕ).

### 4.2 Ενώ εκκρεμεί

- Παρακολουθείτε το status στο dashboard.
- Μπορείτε να κάνετε **Ανάκληση αίτησης** όσο επιτρέπεται (βλ. §5).
- Δεν μπορείτε να αλλάξετε διαστήματα μετά την υποβολή (εκτός αν σας επιστραφεί / ζητηθούν δικαιολογητικά κατά περίπτωση).

### 4.3 Αν σας ζητηθούν δικαιολογητικά

1. Η αίτηση γίνεται **Σε αναμονή δικαιολογητικών**.
2. Ανοίξτε την αίτηση → ανεβάστε τα αρχεία.
3. Όταν τελειώσετε, δηλώστε **Ολοκλήρωση αποστολής** (αν εμφανίζεται το κουμπί).
4. Περιμένετε συνέχεια από το τμήμα αδειών.

### 4.4 Ολοκλήρωση

Όταν η κατάσταση γίνει **Ολοκληρώθηκε**:
- Για κανονική άδεια αφαιρούνται ημέρες από το υπόλοιπό σας.
- Μπορείτε πλέον να ξεκινήσετε **Ανάκληση άδειας** αν χρειαστεί.

## 5. Ανάκληση αίτησης vs Ανάκληση άδειας

| | Ανάκληση **αίτησης** | Ανάκληση **άδειας** |
|--|----------------------|---------------------|
| Πότε | Πριν ολοκληρωθεί | Μόνο όταν είναι Ολοκληρωμένη |
| Κουμπί | «Ανάκληση αίτησης» | «Ανάκληση άδειας» |
| Αποτέλεσμα | Η αίτηση ακυρώνεται | Νέα αίτηση που ακυρώνει (ολικά/μερικά) την άδεια· μπορεί να επιστρέψει ημέρες στο υπόλοιπο |

### Ανάκληση αίτησης — επιτρέπεται όταν η κατάσταση είναι
Υποβληθείσα, Εκκρεμεί πρωτ. ΚΕΔΑΣΥ, Αναμονή δικαιολογητικών, Σε επεξεργασία, Ετοιμασία απόφασης.

**Δεν** επιτρέπεται π.χ. σε: Για πρωτόκολλο ΠΔΕΔΕ, Υγειονομική, Προς υπογραφές, Ολοκληρωμένη.

### Ανάκληση άδειας (ολική / μερική)
1. Ανοίξτε ολοκληρωμένη άδεια → **Ανάκληση άδειας**.
2. Επιλέξτε Ολική ή Μερική και τα διαστήματα.
3. Προεπισκόπηση → υποβολή — ακολουθεί την ίδια έγκριση/διαδικασία με κανονική αίτηση.
4. Όταν ολοκληρωθεί η ανάκληση, ενημερώνεται η αρχική άδεια και (για κανονική) το υπόλοιπο.

Δεν μπορείτε να έχετε δύο ανοιχτές αιτήσεις ανάκλησης για την ίδια άδεια ταυτόχρονα.

## 6. Ειδικές περιπτώσεις

### Κανονική άδεια
Χρειάζεστε επαρκές υπόλοιπο. Αν δεν επαρκεί, η υποβολή αποτυγχάνει.

### Αναρρωτική με ΥΔ
Συνήθως έως **2 ολοκληρωμένες** αιτήσεις ανά έτος. Αν εξαντληθεί το όριο, δεν υποβάλλετε τρίτη.

### Αναρρωτική με ιατρική γνωμάτευση
Μπορεί να ζητηθούν δικαιολογητικά ή διαβίβαση σε Υγειονομική Επιτροπή αν ξεπεραστεί όριο ημερών.

### ΚΕΔΑΣΥ / ΣΔΕΥ
Η αίτησή σας μπορεί πρώτα να περιμένει πρωτόκολλο ΚΕΔΑΣΥ και μετά έγκριση προϊσταμένου.

### Άτυπη άδεια
Μόνο αν το τμήμα σας το επιτρέπει (ξεχωριστή επιλογή δημιουργίας). Συχνά ολοκληρώνεται νωρίτερα στη ροή.

## 7. Τι κάνετε ανά κατάσταση (σύνοψη)

| Κατάσταση | Ενέργειές σας |
|-----------|----------------|
| Πρόχειρη | Επεξεργασία, υποβολή, διαγραφή |
| Υποβληθείσα / ΚΕΔΑΣΥ / Επεξεργασία / Ετοιμασία απόφασης | Προβολή, ανάκληση αίτησης (αν εμφανίζεται) |
| Αναμονή δικαιολογητικών | Ανέβασμα αρχείων, ολοκλήρωση αποστολής, ανάκληση αίτησης |
| Πρωτόκολλο ΠΔΕΔΕ / ΥΕ / Υπογραφές | Κυρίως προβολή / αναμονή |
| Ολοκληρώθηκε | Προβολή, ανάκληση άδειας |
| Απορριφθείσα / Ανακληθείσα αίτηση | Μόνο προβολή |

## 8. Troubleshooting

| Πρόβλημα | Τι να κάνετε |
|----------|----------------|
| Δεν μπορώ να υποβάλω | Ελέγξτε δικαίωμα αίτησης, υπόλοιπο, σύμβαση αναπληρωτή, όριο ΥΔ |
| Κολλημένη σε «Υποβληθείσα» | Περιμένετε προϊστάμενο· αν αργεί πολύ, ενημερώστε υπηρεσία |
| Κολλημένη σε ΚΕΔΑΣΥ πρωτόκολλο | Ενημερώστε γραμματεία ΚΕΔΑΣΥ |
| Δεν βλέπω «Ανάκληση άδειας» | Η άδεια πρέπει να είναι Ολοκληρωμένη και χωρίς άλλη ανοιχτή ανάκληση |
| Μπερδεύτηκα με τις δύο «ανακλήσεις» | Αίτηση = πριν την ολοκλήρωση · Άδεια = μετά |
| Δεν ανεβαίνει αρχείο | Μέγεθος/τύπος αρχείου· δοκιμάστε PDF |
| Υπόλοιπο λάθος | Επικοινωνήστε με χειριστή αδειών |

Για τεχνικό σφάλμα: σημειώστε αριθμό αίτησης, ώρα και μήνυμα οθόνης.
