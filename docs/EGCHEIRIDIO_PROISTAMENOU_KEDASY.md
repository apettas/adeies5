# Εγχειρίδιο Προϊσταμένου ΚΕΔΑΣΥ

**Σύστημα:** ΠΔΕΔΕ — Διαχείριση Αιτήσεων Άδειας  
**Κοινό:** Προϊστάμενοι ΚΕΔΑΣΥ (τμήμα τύπου `KEDASY`)  
**Έκδοση οδηγού:** Ιούλιος 2026  

Συμπληρώνει το [Εγχειρίδιο Προϊσταμένου](EGCHEIRIDIO_PROISTAMENOU.md). Εδώ οι **ιδιαίτερες** ροές ΚΕΔΑΣΥ / ΣΔΕΥ.

---

## 1. Τι επιπλέον ισχύει στο ΚΕΔΑΣΥ

- Αιτήσεις υπαλλήλων ΚΕΔΑΣΥ (και συχνά ΣΔΕΥ που υπάγονται στο ΚΕΔΑΣΥ σας) μπορεί να περνούν πρώτα από **Πρωτόκολλο ΚΕΔΑΣΥ/ΚΕΠΕΑ**.
- Εσείς, ως προϊστάμενος ΚΕΔΑΣΥ:
  - Εγκρίνετε αιτήσεις σε `SUBMITTED` για υπαλλήλους σας / ΣΔΕΥ του γονικού σας ΚΕΔΑΣΥ (όταν είστε ο εγκρίνων).
  - Μπορείτε επίσης να καταχωρείτε **πρωτόκολλο ΚΕΔΑΣΥ** όταν η αίτηση είναι σε `PENDING_KEDASY_PROTOCOL` και ανήκει στο πεδίο σας (ίδιο ΚΕΔΑΣΥ ή ΣΔΕΥ παιδιού σας) — εφόσον έχετε ρόλο Manager/Secretary στο σωστό τμήμα.
- Η γραμματεία ΚΕΔΑΣΥ συχνά κάνει την καθημερινή καταχώρηση πρωτοκόλλου (βλ. [Εγχειρίδιο Γραμματέα ΚΕΔΑΣΥ](EGCHEIRIDIO_GRAMMATEA_KEDASY.md)).

Δεν αντικαθιστάτε τον χειριστή αδειών ΠΔΕΔΕ για πρωτόκολλο ΠΔΕΔΕ / αποφάσεις ΣΗΔΕ.

---

## 2. Ροή ΚΕΔΑΣΥ / ΣΔΕΥ (συνοπτικά)

```text
Υπάλληλος ΚΕΔΑΣΥ ή ΣΔΕΥ υποβάλλει
        ▼
PENDING_KEDASY_PROTOCOL  ← πρωτόκολλο ΚΕΔΑΣΥ (γραμματεία ή εσείς)
        ▼
SUBMITTED                ← έγκριση δική σας (αν απαιτείται)
        ▼
PENDING_PROTOCOL ΠΔΕΔΕ   ← χειριστής αδειών ΠΔΕΔΕ συνεχίζει
        ▼
… απόφαση / ΣΗΔΕ / ολοκλήρωση
```

Αν ο τύπος άδειας **δεν** απαιτεί έγκριση προϊσταμένου, μετά το πρωτόκολλο ΚΕΔΑΣΥ η αίτηση μπορεί να πάει απευθείας σε πρωτόκολλο ΠΔΕΔΕ.

---

## 3. Ενέργειες ανά status (δική σας πλευρά)

| Status | Τι κάνετε |
|--------|-----------|
| Εκκρεμεί Πρωτόκολλο ΚΕΔΑΣΥ/ΚΕΠΕΑ | Καταχώρηση πρωτ. ΚΕΔΑΣΥ **αν** σας εμφανίζεται η ενέργεια· αλλιώς αφήστε στη γραμματεία |
| Υποβληθείσα | **ΕΓΚΡΙΣΗ** ή **ΑΠΟΡΡΙΨΗ** (όπως γενικός προϊστάμενος) |
| Μετά την έγκριση | Παρακολούθηση μόνο· η συνέχεια είναι ΠΔΕΔΕ |
| Δική σας αίτηση | Εγκρίνει ο ανώτερός σας (όχι εσείς) |

### Καταχώρηση πρωτοκόλλου ΚΕΔΑΣΥ
1. Ανοίξτε την αίτηση σε κατάσταση εκκρεμούς πρωτοκόλλου ΚΕΔΑΣΥ.
2. Συμπληρώστε αριθμό πρωτοκόλλου και ημερομηνία.
3. Η αίτηση προχωρά σε Υποβληθείσα (ή απευθείας ΠΔΕΔΕ αν δεν χρειάζεται έγκριση).

### Έγκριση ΣΔΕΥ
Για υπαλλήλους ΣΔΕΥ που ανήκουν στο ΚΕΔΑΣΥ σας ως γονικό τμήμα, μπορείτε να εγκρίνετε όταν το σύστημα σας ορίζει ως εγκρίνοντα (προϊστάμενος ΚΕΔΑΣΥ).

---

## 4. Checklist προϊσταμένου ΚΕΔΑΣΥ

- [ ] Η αίτηση αφορά υπάλληλο του ΚΕΔΑΣΥ σας ή ΣΔΕΥ του ΚΕΔΑΣΥ σας  
- [ ] Αν είναι σε πρωτόκολλο ΚΕΔΑΣΥ: έχει καταχωρηθεί σωστός αρ. πρωτ.  
- [ ] Αν είναι Υποβληθείσα: ελέγξατε διαστήματα/δικαιολογητικά πριν την έγκριση  
- [ ] Απόρριψη μόνο με σαφή αιτιολογία  
- [ ] Δεν εγκρίνετε αίτηση όπου είστε ο αιτών  

---

## 5. Troubleshooting ΚΕΔΑΣΥ προϊσταμένου

| Πρόβλημα | Τι να κάνετε |
|----------|----------------|
| Δεν βλέπω πρωτόκολλο ΚΕΔΑΣΥ | Ίσως το κάνει μόνο γραμματεία ίδιου τμήματος· ή η αίτηση δεν απαιτεί ΚΕΔΑΣΥ πρωτόκολλο |
| ΣΔΕΥ αίτηση δεν εμφανίζεται | Ελέγξτε αν το ΣΔΕΥ έχει γονικό το δικό σας ΚΕΔΑΣΥ |
| Μετά το πρωτόκολλο περιμένει έγκριση | Κανονικό αν ο τύπος απαιτεί έγκριση — εγκρίνετε από Υποβληθείσα |
| Μετά την έγκριση δεν «τελειώνει» | Σωστό — συνεχίζει ο χειριστής ΠΔΕΔΕ |
| Σύγκρουση με γραμματεία | Συμφωνήστε ποιος καταχωρεί πρωτόκολλο· αποφύγετε διπλοεγγραφές |

Για προβλήματα δεδομένων τμήματος/γονικού ΣΔΕΥ ενημερώστε διαχειριστή εφαρμογής.
